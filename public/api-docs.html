1 Daftar Produk

GET /api/products

Ambil daftar produk aktif. Mendukung filter, pencarian, sorting, dan pagination.

Query Parameters (semua opsional)

ParamContohKeterangan
page?page=1Nomor halaman (default 1)
limit?limit=20Jumlah item per halaman (default 20)
category?category=laptop-notebookSlug kategori
brand?brand=lenovoSlug brand
condition?condition=A,BGrade kondisi (A/B/C, pisah dengan koma)
minPrice?minPrice=1000000Harga minimum (rupiah, angka polos)
maxPrice?maxPrice=5000000Harga maksimum
q?q=thinkpadPencarian nama / deskripsi / SKU / brand
inStock?inStock=trueHanya produk dengan stok tersedia
featured?featured=trueProduk unggulan saja
badge?badge=NEWFilter label produk
sort?sort=newestnewest · price_asc · price_desc · popular · rating

Contoh URL

GET https://beliseken.com/api/products?limit=20&inStock=true&sort=newest GET https://beliseken.com/api/products?category=laptop-notebook&brand=lenovo&maxPrice=5000000

2 Detail Produk

GET /api/products/{slug}

Ambil detail lengkap satu produk berdasarkan slug.

GET https://beliseken.com/api/products/lenovo-thinkpad-l13-gen-2

Field Tambahan (di luar field list)

FieldIsi
allImages / imagesArray URL semua foto produk, sudah urut
specsArray spesifikasi { label, value }
unitsUnit fisik tersedia: grade kondisi, skor, catatan, health baterai
reviews10 ulasan terakhir (nama user, rating, komentar)
videoUrlURL video produk (bisa null)
performanceNotesCatatan performa (bisa null)
minusNotesCatatan minus / kekurangan unit (bisa null)
warrantyNotesCatatan garansi (bisa null)
totalReviewsJumlah total ulasan

Error 404

{ "success": false, "error": "Product not found" }

7 Panduan Implementasi

🖼️ Image Loading

Pakai Coil atau Glide. URL sudah auto-optimize (WebP, resize) oleh Cloudinary — tidak perlu transformasi tambahan di client.

📄 Pagination

Ikuti meta.totalPages untuk infinite scroll / load more. Gunakan limit=20 sebagai standar.

⚡ Caching

Response sudah dikirim dengan HTTP cache header. Tambahkan OkHttp Cache / Room di client agar app terasa instan saat offline.

🚨 Error Handling

Jika success: false, tampilkan isi field error ke user. HTTP code: 404 = tidak ditemukan, 500 = server error.

⚠️ Jangan hardcode URL gambar — selalu ambil dari imageBase64 / allImages, karena penyimpanan gambar bisa berubah (base64 → Cloudinary) sewaktu-waktu.
